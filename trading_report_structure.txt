## Service Communication Flow

### 1. Email Arrives
```
Email Provider → Webhook → Traefik → N8N Webhook Node
```

### 2. Report Processing
```
N8N → Playwright Scraper → Returns {text, images, metadata}
    → PostgreSQL (Store raw data)
    → AI Analyzer → Returns {summary, analysis, trades}
    → PostgreSQL (Store analysis)
```

### 3. Notification
```
N8N → Notification Service → [Telegram Bot API, SMTP Server]
```

## Database Schema (PostgreSQL)

### Core Tables
```sql
-- reports
CREATE TABLE reports (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email_received_at TIMESTAMPTZ NOT NULL,
    email_subject TEXT,
    email_from TEXT,
    report_url TEXT NOT NULL,
    raw_content TEXT,
    metadata JSONB,
    status VARCHAR(50) DEFAULT 'pending',
    error_message TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- images
CREATE TABLE report_images (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    report_id UUID REFERENCES reports(id) ON DELETE CASCADE,
    image_url TEXT,
    image_data BYTEA,
    image_type VARCHAR(50),
    sequence_order INT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- analyses
CREATE TABLE analyses (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    report_id UUID REFERENCES reports(id) ON DELETE CASCADE,
    ai_provider VARCHAR(50) NOT NULL,
    model_used VARCHAR(100),
    summary TEXT NOT NULL,
    key_trades JSONB,
    market_analysis TEXT,
    recommendations TEXT,
    sentiment VARCHAR(50),
    confidence_score DECIMAL(3,2),
    tokens_used INT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- notifications
CREATE TABLE notifications (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    analysis_id UUID REFERENCES analyses(id) ON DELETE CASCADE,
    channel VARCHAR(50) NOT NULL, -- 'telegram' or 'email'
    status VARCHAR(50) DEFAULT 'pending',
    sent_at TIMESTAMPTZ,
    error_message TEXT,
    retry_count INT DEFAULT 0,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Indexes
CREATE INDEX idx_reports_created_at ON reports(created_at DESC);
CREATE INDEX idx_reports_status ON reports(status);
CREATE INDEX idx_analyses_report_id ON analyses(report_id);
CREATE INDEX idx_notifications_status ON notifications(status);
```

## API Contracts

### Playwright Scraper Service
**Endpoint**: `POST /api/v1/scrape`

**Request**:
```json
{
  "url": "https://example.com/report/123",
  "credentials": {
    "username": "user@example.com",
    "password": "secure_password"
  },
  "options": {
    "timeout": 60000,
    "extract_images": true,
    "screenshot": true
  }
}
```

**Response**:
```json
{
  "success": true,
  "data": {
    "text_content": "Full report text...",
    "images": [
      {
        "url": "https://...",
        "base64": "data:image/png;base64,...",
        "type": "tradingview_chart"
      }
    ],
    "metadata": {
      "page_title": "Trading Report - Nov 2025",
      "scraped_at": "2025-11-25T10:30:00Z",
      "duration_ms": 5432
    }
  }
}
```

### AI Analyzer Service
**Endpoint**: `POST /api/v1/analyze`

**Request**:
```json
{
  "content": "Report text content...",
  "images": ["base64_image_1", "base64_image_2"],
  "provider": "anthropic",
  "analysis_type": "comprehensive"
}
```

**Response**:
```json
{
  "success": true,
  "analysis": {
    "summary": "Market showed bullish momentum...",
    "key_trades": [
      {
        "symbol": "EUR/USD",
        "action": "BUY",
        "entry": 1.0850,
        "exit": 1.0920,
        "result": "profit"
      }
    ],
    "market_sentiment": "bullish",
    "recommendations": "Consider long positions...",
    "confidence": 0.85
  },
  "metadata": {
    "model": "claude-sonnet-4-20250514",
    "tokens": 1250
  }
}
```

## Best Practices Implemented

### 1. **Code Quality**
- Type hints everywhere (Python 3.12+)
- Pydantic models for validation
- Ruff for linting and formatting
- Pre-commit hooks
- 100% test coverage goal

### 2. **Security**
- No secrets in code (env vars only)
- API authentication on all services
- Rate limiting on endpoints
- Input validation and sanitization
- Secure credential storage

### 3. **Observability**
- Structured logging (structlog)
- Request tracing with correlation IDs
- Metrics collection (Prometheus)
- Health check endpoints
- Error tracking and alerting

### 4. **Resilience**
- Retry logic with exponential backoff
- Circuit breakers
- Timeout configurations
- Graceful degradation
- Database connection pooling

### 5. **Performance**
- Async/await patterns
- Connection pooling
- Caching strategies
- Background task processing
- Resource limits in Docker

### 6. **Development**
- Hot reload in development
- Docker Compose for local dev
- Makefile for common commands
- Comprehensive documentation
- Integration and E2E tests

## Monitoring & Alerts

### Key Metrics to Track
- Email processing time
- Scraping success rate
- AI analysis latency
- Notification delivery rate
- Error rates by service
- Database query performance

### Alert Conditions
- Scraping failure > 2 consecutive
- AI API errors > 5 in 10 minutes
- Notification delivery failure
- Database connection issues
- Disk space < 20%
- Memory usage > 80%
